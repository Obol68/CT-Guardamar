GESTOR CT GUARDAMAR – CORRECCIÓN DE INICIO Y COMPATIBILIDAD

Esta versión corrige dos problemas que podían dejar la pantalla central en blanco:
1. Un cierre prematuro de la etiqueta <script> dejaba el código principal fuera de JavaScript.
2. El código usaba sintaxis y métodos modernos que no existen en WebView antiguos.

CAMBIOS
- Se deja todo el código ejecutable dentro de un único bloque JavaScript.
- Se transpila el programa a JavaScript ES5 para mejorar la compatibilidad con WebView antiguos.
- Se incorporan compatibilidades para flat, flatMap, fromEntries, matchAll y padStart.
- Se mantiene el aviso visible de errores de inicio.
- Se mantiene la copia precargada del Torneo de Navidad 2026 con sus nueve parejas inscritas.
- Se incrementa la versión Android a 1.1 (versionCode 2).
- Se conserva la misma aplicación (mismo applicationId) para permitir actualizarla sin desinstalar.

CÓMO GENERAR LA APK EN GITHUB
1. Descomprime este ZIP en el ordenador.
2. Abre el repositorio CT-Guardamar en GitHub.
3. Sustituye los archivos del repositorio por los de esta carpeta. IMPORTANTE: las carpetas app y .github deben quedar directamente en la raíz del repositorio; no metas todo dentro de una carpeta adicional.
4. Guarda los cambios en la rama main.
5. Entra en Actions y abre la ejecución más reciente de “Build CT Guardamar APK”.
6. Cuando termine en verde (Success), descarga el artefacto “CT-Guardamar-APK”.
7. Extrae el ZIP del artefacto y copia app-debug.apk a la tablet.
8. Pulsa la APK descargada y elige INSTALAR para actualizar la aplicación existente.

IMPORTANTE
- No desinstales la versión instalada: actualizar encima conserva los datos de la aplicación.
- No borres los datos ni el almacenamiento de CT Guardamar Torneos.
- Si Android dice “Aplicación no instalada” o advierte que el paquete no es compatible, no desinstales nada: envía una foto del mensaje.
- Después de actualizar, abre el icono CT Guardamar Torneos desde la lista de aplicaciones, no desde el archivo APK.
